# amanv8060/homebrew-tap

[Homebrew](https://brew.sh) casks and formulae for my apps.

```bash
brew tap amanv8060/tap
brew install --cask <cask>   # or: brew install <formula>
```

## Casks

| Cask | Description |
| --- | --- |
| [`claude-switcher`](Casks/claude-switcher.rb) | [Claude Switcher](https://github.com/amanv8060/claude-switcher): switch between Claude accounts and check their usage limits from the menu bar. |

Each app's release workflow updates its entry here automatically.
